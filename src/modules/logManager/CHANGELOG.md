# 📌 CHANGELOG - logManager

Todas las modificaciones y mejoras del sistema de logging se registrarán aquí.

## [1.0.0] - 2025-05-22

### ✨ Características principales

- Sistema modular de logging con soporte para `txt` y `json`.
- Gestión de niveles de log (`DEBUG`, `VERBOSE`, `TRACE`).
- Configuración centralizada (`logConfig.js`).
- Estructura optimizada para escalabilidad (`logManager.js`, `guardarLog.js`).
- Manejo robusto de errores y validación de formatos.

### 🛠 Mejoras previstas para futuras versiones

- Implementar **rotación de logs** para evitar acumulación innecesaria.
- Agregar soporte para nuevos formatos de registro (`.CSV`, `.XML`).
- Permitir configuración dinámica a través de un archivo externo o variables de entorno.
- Integración con herramientas de monitoreo.
